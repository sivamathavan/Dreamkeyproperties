# DreamKey Properties - Static Real Estate Showcase

An elegant, premium real estate showcase website built using purely static technologies (HTML5, CSS3, and Vanilla JavaScript).

## 🚀 Vision
A lightweight, fast, and SEO-optimized platform for displaying luxury real estate inventory. Focused on high-end aesthetics and seamless user interaction without the overhead of a backend.

## 📁 Project Structure
- `index.html`: Homepage with featured properties and brand intro.
- `listings.html`: Searchable inventory with advanced filters.
- `property.html`: Dynamic detail page with gallery and inquiry options.
- `about.html`: Company narrative and mission.
- `services.html`: Detailed service offerings.
- `contact.html`: Multi-channel contact options.
- `admin.html`: Simulation dashboard for inventory management.
- `css/style.css`: Premium design system and layout.
- `js/data.js`: Centralized data store and logic handlers.
- `js/main.js`: Global UI behaviors.

## 🛠️ Features
- **Dynamic Rendering**: Property cards and details are generated from a centralized JavaScript array.
- **Client-Side CRUD**: The Admin page allows adding, editing, and deleting properties (persisted via `localStorage`).
- **Advanced Filtering**: Filter listings by type, status, and maximum price in real-time.
- **Deep Linking**: WhatsApp and Email links are dynamically generated with property context.
- **Responsive Design**: Fluid layouts for mobile, tablet, and desktop.

## 💻 Local Development
1. Clone or download the project files.
2. Open `index.html` in any modern web browser.
3. No build step or local server is required, though using a live server (VS Code Live Server) is recommended for the best experience.
